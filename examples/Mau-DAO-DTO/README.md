# 11 file gốc DAO/DTO người dùng gửi

Giữ nguyên byte 6 DAO và 5 DTO để đối chiếu. Những file này không nằm trong Compile của project chính.

Bản chạy nằm ở DAO/ và DTO/, sử dụng VeMayBay, MySql.Data.MySqlClient và tên *DTO theo mẫu. Có thêm phần tích hợp BUS, đọc/ghi NULL, mapping LoaiKH → LoaiHK, tham số hóa câu SQL hãng hàng không và kiểm tra giao dịch. Xem docs/DONG_BO_MAU_DAO_DTO.md ở gốc repository.
