# Bản gốc 5 file DAO người dùng gửi

Các file .cs trong thư mục này giữ nguyên byte theo bản tải lên, dùng namespace VeMayBay, các lớp *DTO và MySql.Data.MySqlClient. Đây là bản đối chiếu, không được biên dịch trong project hiện tại.

Bản tích hợp nằm tại DAO/ tương ứng: chỉnh namespace/tên DTO/provider cho QuanLyMayBay, giảm giá dùng decimal, hỗ trợ NULL theo schema, ánh xạ LoaiKH sang LoaiHK. Các hàm SQL và tham số theo file gốc được giữ; thêm phần tương thích Doc/Luu, ghi nhận snapshot và các kiểm tra giao dịch đã có.
